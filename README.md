# Projeto UWine - TCC

Este repositório é um estudo de caso em Ciência de Dados, utilizando o caso fictício da UVWine para aplicar os metodos aprendidos durante o curso como: estatística descritiva, análise de dados e o machine learning em Python.

## Objetivo do trabalho

O projeto está organizado em duas etapas:

* **Parte 1:** definição e validação do tamanho amostral, estratificação da população (grupos ESSENTIAL, PRIME e VIP), análise da convergência do erro-padrão, testes de hipóteses e bootstrap.
* **Parte 2:** pipeline de machine learning com dados de treino, validação e teste para tarefas de regressão, classificação e clusterização.
